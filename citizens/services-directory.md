# Government Services Directory

_Last reviewed: November 2026._

One-stop links for common citizen services.

| Need | Where to go |
|---|---|
| Government news and information | [gov.sg](https://www.gov.sg) |
| Log in to government services | [Singpass](https://www.singpass.gov.sg) |
| Life events (having a baby, moving, retiring) | [LifeSG](https://www.life.gov.sg) |
| NRIC, passport, immigration | [ICA](https://www.ica.gov.sg) |
| CPF | [CPF Board](https://www.cpf.gov.sg) |
| Taxes | [IRAS](https://www.iras.gov.sg) |
| Housing | [HDB](https://www.hdb.gov.sg) |
| Health | [MOH](https://www.moh.gov.sg) / [HealthHub](https://www.healthhub.sg) |
| Schools and education | [MOE](https://www.moe.gov.sg) |
| Skills training | [SkillsFuture](https://www.skillsfuture.gov.sg) |
| Jobs and employment rules | [MOM](https://www.mom.gov.sg) |
| Report municipal issues (e.g. cleanliness, faulty lights) | [OneService](https://www.oneservice.gov.sg) |
| Government updates on WhatsApp | [Sign up](https://go.gov.sg/whatsapp) |
| Report scams | [Police](https://www.police.gov.sg) |

> Tip: Use the official `.gov.sg` address. Be wary of look-alike sites.
